# Assets

Every non-code asset in this repository is listed here with its origin and licence. Nothing is copied from another brand.

## Fonts

| Asset       | Source                          | Licence           | Loaded via         |
| ----------- | ------------------------------- | ----------------- | ------------------ |
| Archivo     | Google Fonts (Omnibus-Type)     | SIL Open Font 1.1 | `next/font/google` |
| Inter Tight | Google Fonts (Rasmus Andersson) | SIL Open Font 1.1 | `next/font/google` |

Fonts are fetched at build time by `next/font` and self-hosted from the build output. No runtime requests go to Google.

## Imagery

All imagery is generated by the seed script (`prisma/seed/lib/placeholders.ts`) and written to `public/images/`. Each file is a flat-colour SVG with one geometric shape and the product or section name. They are original, carry no third-party rights, and are committed so the store renders straight after a clone.

| Folder                       | Files | What                                                      |
| ---------------------------- | ----- | --------------------------------------------------------- |
| `public/images/products/`    | 170   | Two views per colour per product, 900 × 1200 (3:4)        |
| `public/images/categories/`  | 32    | One tile per category, 800 × 1000                         |
| `public/images/collections/` | 3     | Collection heroes, 1600 × 900                             |
| `public/images/banners/`     | 5     | Home hero and editorial slots, 1920 × 1080 or 1200 × 1500 |

`next.config.ts` allows SVG through `next/image` with a content security policy that blocks scripts inside images. Replace these with real photography before launch and update this table. Re-running the seed regenerates them.
